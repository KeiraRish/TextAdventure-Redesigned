# Text Adventure-Redesigned

This Apartment Text Adventure was one of my first big computer science projects I made in college. It has always been my favorite program so I decided to give it a redesign. Made in Streamlit to showcase the skills learned during my internship.

## Shared leaderboard setup

For shared leaderboard entries that survive app restarts and are visible across website visitors, configure a Supabase project:

1. In the Supabase SQL editor, create the table and access policies:

   ```sql
   create table public.leaderboard (
       id bigint generated by default as identity primary key,
       name text not null check (char_length(name) between 1 and 40),
       score integer not null,
       created_at timestamptz not null default now()
   );

   alter table public.leaderboard enable row level security;
   grant select, insert, update on public.leaderboard to anon;
   grant usage, select on sequence public.leaderboard_id_seq to anon;

   create policy "Anyone can read leaderboard"
       on public.leaderboard for select to anon using (true);
   create policy "Anyone can add leaderboard scores"
       on public.leaderboard for insert to anon with check (true);
   create policy "Anyone can replace leaderboard scores"
       on public.leaderboard for update to anon using (true) with check (true);
   ```

2. In the app host's Streamlit secrets settings, add the Supabase project URL and anon key:

   ```toml
   [supabase]
   url = "https://YOUR_PROJECT.supabase.co"
   anon_key = "YOUR_SUPABASE_ANON_KEY"
   ```

   The URL and anon key are available in the Supabase project's API settings. Use the project URL (without `/rest/v1`). Do not put secrets in the repository.

When these secrets are present, the app reads and writes the shared Supabase table. Without them, local development uses `leaderboard.sqlite3`; that local fallback is not shared between app instances and may not survive restarts on hosts with ephemeral filesystems.
